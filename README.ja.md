# マイゲームブック（我的游戏簿）

> [English](README.en.md) · **日本語** · [简体中文](README.md)

**macOS + iOS** 対応の個人アプリ。ゲームライブラリとクリア履歴を記録できます：ステータス（プレイ予定 / プレイ中 / クリア済み…）、カバー画像、6 軸スコア、プレイごとのプラットフォーム / クリア日 / クリア度 / プレイ時間 / メモ、実物コレクション（エディション / 数量 / 写真）、さらに共有用画像の生成も。完全ローカル保存（SwiftData）、データはすべて自分のもの。

対応言語：**简体中文 / 日本語 / English**（設定で即時切り替え）。macOS と iOS はそれぞれローカルに独立保存し、JSON バックアップでデータを移行できます（AirDrop 対応）。

## 機能

- **ゲームライブラリ**：名前 + 別名 + 多言語名で検索；ステータス / プラットフォーム / グループで絞り込み；グループ管理（macOS サイドバー / iOS フィルターメニュー）、1 つのゲームを複数グループに入れられます；名前 / 発売日 / クリア日 / 平均点（低い順 / 高い順）/ **最近編集した順** / **価値が高い順** で並び替え、初期値は「最近編集した順」。ライブラリ表示スコア = そのゲームの採点済みクリア記録の平均点の平均、0.1 に丸め；未採点は「未評価」表示。
- **お気に入り**：カードの右クリック / 長押しメニュー、または詳細ページのツールバーのハートでワンタップ登録 / 解除（カードにはハートバッジで状態表示、macOS メニューは実心 ♥ / 空心 ♡ で区別）。サイドバーの「グループ」セクション先頭に「お気に入り」仮想グループが常駐（iOS はフィルターメニューのグループ先頭）、統計ブロック付きで通常のグループと共存します。
- **ライブラリ ホームカルーセル**（「すべてのゲーム」ページ上部・5 ページ横めくり + タップでジャンプできるドット）：① ホームバナー（カスタマイズしたタイトル / サブタイトル / 背景 + 大きなアバター）② ランダムゲーム（入場のたびにライブラリ全体から 1 本ランダム——横長カバーを全面に敷き、右上に「平均点」カプセルとレビュータイトル。横図が無いゲームはグリッド同サイズの 2:3 カバー + 右側文字にフォールバック、右上で再ランダム。背景は設定で「自動（横画像優先）/ 背景画像のみ / 横長カバーのみ」を選択でき、iPad は横画面と縦画面で別設定）③ お気に入り（1:1 カバーで 1 本をランダム先頭、残りはリスト）④ ライブラリ概要（本数 / 平均点 / プレイ予定 / クリア済み・長期 + 6 状態分布）⑤ コレクション概要（版数 / 総数 / 支出 / 推定価値）。カードはウィンドウ幅いっぱいで内容も連動、macOS はページ間に隙間を置いてスナップ、iOS はネイティブのページめくり。iPad 横画面ではカードが自動でフラット化され、拡大が暴走しません。iOS の「すべてのゲーム」タイトルはカルーセルの下に置かれ、コンテンツと一緒にスクロールします。
- **ビュー（端末別）**：**macOS** はグリッド / リスト切替 + サイドバー；**iPhone** は 3 択ビュー——グリッド / **1 列ワイドカード**（スクエアカバーがカードの高さを目一杯満たして端まで敷き詰められ、無い場合は縦長カバーを高さに合わせて中央配置。ガラス素材の角丸カード背景 + 細いボーダー + 影、スコアカプセルはカバー右上に重なり、右列はタイトル + プラットフォーム + メタデータの文字領域）/ リスト。選択は起動間で記憶され、旧設定から自動移行します。**iPad** はワイドカードが** 2 列レイアウト**に（横画面：横型カードで左図右文、カード高とフォントもアップグレード；縦画面：縦型カードで上図下文、カバーは列幅いっぱい、5 項目のメタデータをすべて表示）。**グリッド最小表示**（全プラットフォーム）：オンにするとグリッドはカバーと右上のスコア/状態カプセルのみ表示し、名前・プラットフォーム・日付は隠します。
- **ゲームステータス**：プレイ予定 / プレイ中 / 中断 / ギブアップ / クリア済み / 長期プレイの 6 状態。軽量な状態ではクリア記録やスコアは不要で、クリア済み・長期プレイに移した時に記録が付きます。ライブラリをステータスで絞り込み、詳細ページではリキッドガラスのスライダーで選択（両プラットフォーム共通でスコア領域の下）；未クリアのゲームもゲームレベルのプラットフォームを持ち、絞り込みと統計に参加します。
- **ゲーム詳細**：レビューエリア（一言タグラインの導入文 + 長文本文）、全クリア記録（編集 / 追加 / 削除）、6 軸カラーバーチャート；開発元 / パブリッシャー / ジャンルの 3 つの任意フィールド；コレクターモード有効時は「所持」タブが追加。**iOS のタイトル改行は単語境界**：大きなタイトルを NLTokenizer で分語し、改行は単語の境界にのみ落ちるため、「遺|言」のような単語途中の折り返しは起きません。
- **詳細ヘッダー（端末別）**：**macOS** の幅広ウィンドウは「カバーバンド + 情報列 + ガラススコアカード」レイアウトで、幅を狭めると 1 列にフォールバック；背景画像バナー（元画像を切り取らず完全表示、ページ上部に寄せ、幅いっぱい、高さはウィンドウと画像比率に連動）+ ロゴ（透過 PNG。サイズ / 縦位置 / 横位置を各 3 段階ずつゲームごとに調整、カバーと比率が固定連動）を設定可能。**iPad** の横画面は macOS 同様のヒーローレイアウト（ヒーローバナー + ロゴ前景 + 28pt マージン）；縦画面では横長カバーを満幅表示（高さ上限を 560pt に緩和、余白なし）；採点済みゲームは横縦ともスコアカードを情報列の右に置きます（macOS 同様の 2 列）。**iPhone** は横長カバーを設定すると満幅バナーレイアウトに切り替わり（ナビゲーションバー直下に寄せ、高さは画像比率から算出、上限 260pt、切り取りなし）、未設定なら従来レイアウトのまま。
- **レビュー（Markdown 長文）**：一言レビュー（タグライン）を大きな導入文として見出し的に表示；長文本文は Markdown サブセット（見出し `#` / 太字 `**` / 斜体 `*` / リスト `-`）に対応し、組版が行き届いた記事のようになります。**macOS = リッチテキスト WYSIWYG エディタ**（独立した「書き机」ウィンドウ。ツールバーで直接スタイル変更、保存時に Markdown へ変換。CJK 斜体は描画時にシェアで合成）；**iOS = 編集シート（TextEditor）**。端末ごとに編集しつつ、共通の Markdown レンダラで両端の見た目は一致します。
- **6 軸スコア**：ゲームプレイ / デザイン / ストーリー / アート / ミュージック / パフォーマンス、1–10、0.1 刻みのスライダー。総合 = 6 軸の平均；最初のクリア記録では必須、以降はスキップ可能。
- **クリア記録**：プラットフォーム、クリア日（「なし」可）、クリア度（メインストーリー / 全サブクエスト / 全エンディング / 全コレクションプラチナ / マルチ周回 / スピードラン / カスタム）、プレイ時間（「なし」可）、メモ。
- **日付選択**：macOS は 3 連ホイール（年 / 月 / 日、閏日と月末の調整に対応；システムホイールに揃えたスプリング吸着の手触り）；iOS はシステムの日付ピッカー。
- **グループ**：作成 / 改名 / 削除；右クリック（macOS）またはメニュー（iOS）からゲームを追加；グループ統計とグループレビュー（Markdown で表示、macOS は「書き机」で編集可）。
- **コレクターモード**（設定トグル）：詳細ページに「詳細 / 所持」のセグメント切替；各ゲームに複数の所持版（媒体 11 種 / 地域 10 種 / コンディション 7 種 / 入手元 11 種 / 言語別価格と推定価値 / 購入日 / メモ + 最大 6 枚の写真）を持て、それが**コレクション档案**となります。新規作成時は初期状態では所持を作らず、「この版を所有（所持档案を作成）」をオンにして初めてフィールドが展開されます。所持ビューはグリッド / リストの両表示、トップの総覧（版数 / 総数量 / 総支出 / 総推定価値）、カプセル式メタデータ、完全な編集シートに対応；写真はシステムビューアで表示、バックアップに含まれます。
- **カバーと画像**：端末から選択（iOS は「写真 / ファイル / 撮影」メニュー）、または [SteamGridDB](https://www.steamgriddb.com) API で検索してダウンロード（設定で API Key が必要、入力中に自動検索、検索結果はサムネイル表示）；5 種類の画像それぞれに**自動マッチ**トグル（縦カバー / スクエアカバー / 横カバー / 背景画像 / ロゴ——名前入力が約 0.6 秒止まった時点で最初のヒットを取得、既存画像は上書きせず、失敗時は静かに無視；名前変更でも再取得）；スクエアカバーは 1:1 の結果のみ（512×512 と 1024×1024 の両サイズを検索）；検索シートの文言は画像種別ごとに変わり、ゲームの英語名を事前入力。
- **パーソナライズ**：ユーザー名（20 文字）、アバター（円形クロップ）、macOS アプリアイコン（角丸矩形クロップ）、自動マッチカバー、上部毛ガラス非表示（macOS 15+）、元画像保持、プラットフォームロゴ（初期値オン、オフでロゴ非表示）の各トグル。カスタムアイコンは Dock に即反映され、再起動後も維持。
- **共有画像（beta 2.4 で全面リニューアル）**：ブランド固定のダークビジュアル——暖色の近黒背景 + 系統色は琥珀オレンジ；プレビューパネル自体はシステムの外観に追従（2026-08-27 調整）。3 種類のカード：
  - **単体カード**：ぼかしたカバーの下敷き + 実比率でフレームを満たす鮮明ポスター（SteamGridDB の縦 2:3 でも余白なし）；情報パネルにはゲーム名 / プラットフォーム / 発売年 / クリア度カプセル / 一言レビュー（ゴールド）/ 6 軸ミニバー / 大きなライブラリスコア。未クリアのゲームはカラフルなステータスバッジを表示。
  - **総覧画像**：ヘッダーの集計行と各ゲームタイルのフィールドはどちらも「スタイル設定」で選択・並び替え可能（集計：タイトル数 / 平均点 / クリア総数 / コレクション価値；タイル：プラットフォーム / スコア / 最近のクリア日 / 発売年 / ステータスラベル）。列数は枚数に応じて自動調整、キャンバスは内容に合わせて伸びます。
  - **グループカード**：タイトル + 一言グループレビューの引用 + 統計要素（平均点 / タイトル数 / クリア数 / 最高スコア作品 / コレクション価値、選択・並び替え可）+ プラットフォーム分布バー + グループ内カバーグリッド。スマホ / デスクトップの 2 レイアウト。
  - 「スタイル設定」で上記 3 つの要素プールを一括設定、総覧タイルとグループタイルは同じフィールド設定を共有。書き出しは JPEG（初期値）/ PNG を選択可、ファイル名にゲーム / グループ名が自動付与。iOS はプレビューをタップでフルスクリーン表示、アルバムへ直接保存（写真追加権限が必要）。透かし（ユーザー名のゲームブック + アバター）は言語ごとにローカライズ。
- **統計 & ランキング**：クリア総数、ライブラリ平均点（プレイ予定数も表示）、プラットフォーム分布、コレクション価値（コレクターモード時は版数 / 総数量 / 総支出 / 総推定価値）；平均点ランキング + 6 軸ランキング（各軸トップ 5 / 10）；「総合ランキング」ページ上部で **スコア順 / 価値順** を切替——スコア順は平均 + 6 軸の計 7 ランキング、価値順は「ゲーム価値順 / 機種価値順 / グループ価値順」の 3 ページを持ち、それぞれ 1 ページ最大 100 件でページング、プラットフォーム絞り込み可。
- **バックアップ**：ライブラリ全体を 1 つの JSON に書き出し（カバーは base64 埋め込み）、ユーザー名 / アバター / アイコンも含めて一括復元可能、旧バージョンのバックアップにも互換；インポート時は確認ダイアログ。iOS の書き出しはシステム共有シート（AirDrop / ファイルに保存 等）で、ファイル名にタイムスタンプが付きます。
- **自動バックアップ**：データが変わるたびに完全なバックアップを自動でローカル保存（上書き式の単一ファイル）；バージョンアップ前は旧バージョンのスナップショットを自動保存；ライブラリが空でもバックアップにデータがあれば起動時に復元を確認；復元 / インポート前にもスナップショットを残し取り消し可能。iOS では Documents/Backups に保存されるため（「ファイル」app で見える）、署名切れなどでアプリが開けなくてもファイルを取り出せます。
- **キャッシュ削除**：設定 → ストレージとキャッシュ で現在のキャッシュ容量を表示し、ワンタップで削除（カバー/画像デコードキャッシュ、ネットワークキャッシュ、一時ファイル）。ゲームデータとバックアップには一切影響しません。

## 環境要件

- macOS 14.0+；iOS 18.0+（iPhone / iPad）
- **Xcode 27 beta**（本プロジェクトは macOS 27 / iOS 27 の SDK とシミュレータランタイムを必要とします。ビルドには `/Users/abc/Downloads/Xcode-beta.app` を使用）

## ビルド & 実行

```bash
cd /Users/abc/Documents/gamelog_program

# macOS ビルド + 起動（macOS 27 beta では beta Xcode が必須）
DEVELOPER_DIR=/Users/abc/Downloads/Xcode-beta.app/Contents/Developer \
xcodebuild -project GameLog.xcodeproj -scheme GameLog -configuration Debug \
  -destination 'platform=macOS' -derivedDataPath /tmp/GameLogDD-mac build
open /tmp/GameLogDD-mac/Build/Products/Debug/GameLog.app

# iOS シミュレータ ビルド + インストール + 起動
DEVELOPER_DIR=/Users/abc/Downloads/Xcode-beta.app/Contents/Developer \
xcodebuild -project GameLog.xcodeproj -scheme GameLog-iOS -configuration Debug \
  -destination 'platform=iOS Simulator' -derivedDataPath /tmp/GameLogDD-ios build
xcrun simctl install booted /tmp/GameLogDD-ios/Build/Products/Debug-iphonesimulator/GameLog.app
xcrun simctl launch booted com.abcleg.GameLog
```

または Xcode で `GameLog.xcodeproj` を開き、`GameLog`（macOS）または `GameLog-iOS`（iOS）スキームで Run します。

## Demo データを試す

リポジトリには本アプリの機能を確認するための生成済みデモデータ（[GameLog-demo-backup.json](GameLog-demo-backup.json)）が付属しています：50 タイトル（中国語 / 英語 / 日本語名 + 発売日）、105 件のクリア記録（Nintendo Switch 2 / PS5 / Xbox Series X|S / PC に分散、下位互換の痕跡含む）、6 軸スコア、9 グループ。

インポート方法：

1. iOS：JSON を「ファイル」app に配置；macOS：ローカルに配置
2. アプリ → 設定 → バックアップ → **インポート** → ファイルを選択 → 確定

注意：インポートすると現在のデータが置き換わります。

## SteamGridDB カバー検索

1. [steamgriddb.com](https://www.steamgriddb.com) で無料登録し、プロフィールページから API Key を取得。
2. アプリの設定 → SteamGridDB に Key を入力（キー欄は表示/非表示・コピーに対応、変更時に自動検証し ✓ 有効 / ✗ 無効 を表示）。
3. ゲーム作成 / 編集時に、必要な画像種別の検索ボタン（縦カバー / スクエアカバー / 横カバー / 背景画像 / ロゴ）をタップ。

## 開発検証

`Scripts/` に再実行可能な独立リグレッションテストがあります（beta Xcode ツールチェーンの `swiftc` でコンパイル、マクロプラグインのパスは各ファイルの冒頭コメント参照）：

- `Scripts/ScoreMathSelftest/` — スコア計算のセルフテスト（丸め / 平均 / ライブラリ表示スコア）
- `Scripts/DataSmokeTest/` — データ層スモーク：多対多、カスケード削除、採点統合、バックアップ往復、インポート冪等性と置換、コレクション档案のマイグレーションとバックアップ、日付の忠実性、プリセットのローカライズ
- `Scripts/ShareRenderTest/` — 共有カード描画パイプライン：ImageRenderer で実際に PNG を出力し、サイズ / 列数 / JPEG エンコード / 要素プール設定の往復を検証
- `Scripts/RichReviewTest/` — レビューエディタの核心不変式：Markdown → リッチテキスト → Markdown の往復が文字単位で一致

UI 文言を追加するときは、key を 3 つの `Localizable.strings` すべてに追加し、`L10n.tr` / `LText` を使います（`String(localized:)` は不可）。変更後は key 網羅チェックを実行し、3 言語すべて 0 欠落にすること（コマンドは HANDOVER.md §2）。
